# AutoLogistics

Pet-проект для моделирования логистических перевозок автозапчастей между складами
с использованием алгоритмов поиска кратчайших путей.

## 🚀 Цели проекта
- Отработка алгоритмов (Dijkstra)
- Применение принципов ООП
- Подготовка к техническим собеседованиям (Java)
- Основа для дальнейшего перехода к Spring и БД

## 🧠 Используемые технологии
- Java 17
- Collections Framework (List, Map, Set)
- Алгоритмы графов
- Git / GitHub

## 🏗 Архитектура проекта
Проект разделён на логические модули:

- `logistics` — доменные сущности (Warehouse, Part)
- `graph` — граф и маршруты
- `algorithm` — алгоритмы поиска кратчайших путей (Dijkstra)
- `Main` — точка входа, сценарий работы

## 📦 Основные сущности
- **Warehouse** — склад автозапчастей
- **Part** — автозапчасть
- **Route** — маршрут между складами
- **Graph** — граф логистической сети

## 🛣 Алгоритмы
Реализован алгоритм Дейкстры для поиска кратчайших маршрутов между складами.

Алгоритм вынесен в отдельный класс и не зависит от источника данных.
